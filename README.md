## Financial Risk Analysis & Loan Portfolio Dashboard
## Overview:
An Excel dashboard developed for InstaBank to analyze loan portfolio performance, customer credit risk, regional default patterns, and lending trends.

## Tools Used:
Microsoft Excel
Pivot Tables
Pivot Charts
XLOOKUP
COUNTIFS
SUMIFS
Conditional Formatting
Interactive Slicers
## Dashboard Preview
images/dashboard-overview.png

## Key KPIs
Total Loans: 1000
Total Loan Portfolio: ₹1.08 Billion
Default Loans: 196
Paid Loans: 804
Default Rate: 19.6%
Average Credit Score: 721

## Business Insights
East region has the highest defaults.
Personal and Business Loans contribute most risk.
Lower credit score groups show higher default concentration.
Dashboard enables proactive risk monitoring.
